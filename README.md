# Test Rig

This repository contains the mechanical, electronic, firmware, and computer vision components developed for the test rig of the autonomous sorting system.

## 1. Mechanical Assembly

The test rig was fabricated using a combination of **MDF components and 3D-printed parts**.

### 3D-Printed Components

The following components were designed and 3D printed:

* **Phone Mount** – used to securely position the phone camera for object inspection.
* **Driver Roller** – designed with an embedded coupler for direct connection to the **NEMA 17 stepper motor**.
* **Non-Driver Roller** – used to support and guide the conveyor belt.
* **L-Clamps** – used for mounting and securing different components of the rig.

The phone mount was provided with the required offset using **nuts, bolts, and studs**, allowing its position to be adjusted relative to the conveyor and inspection area.

### MDF Structure

The main structure of the test rig was fabricated using **MDF (Medium-Density Fibreboard)**. Cutting, drilling, and other basic fabrication processes were used to create the required base and mounting structure.

The MDF structure was then assembled with the 3D-printed components to form the complete test rig.

## 2. Conveyor System

The conveyor mechanism consists of two rollers:

* **Driver Roller** – connected to the NEMA 17 stepper motor through an embedded coupler.
* **Non-Driver Roller** – provides support and allows the conveyor belt to rotate freely.

The stepper motor drives the conveyor, allowing objects to be transported through the inspection and sorting sections.

## 3. Sorting Mechanism

A **Futaba S3003 servo motor** is used for the sorting mechanism.

The servo rotates the sorter according to the classification of the detected object, directing the object towards the appropriate sorting path.

## 4. Firmware

The control system is implemented using an **ESP32**.

Two Arduino `.ino` files were developed for controlling the motors:

* **Stepper Motor Firmware** – contains the instructions required to control the NEMA 17 stepper motor and conveyor movement.
* **Servo Motor Firmware** – contains the instructions required to control the Futaba S3003 servo and operate the sorting mechanism.

The firmware enables the mechanical system to respond to commands generated by the computer vision system.

## 5. Computer Vision

A **classical Computer Vision (CV)** approach was developed for object inspection and classification.

The CV system processes the video stream obtained from the phone camera and performs image processing to identify and classify the objects.

The pipeline uses image-processing techniques such as:

* Image acquisition from the phone camera
* Image preprocessing
* Thresholding and segmentation
* Contour detection
* Inner-contour analysis
* Object classification
* Consecutive-frame verification to improve classification reliability

The classification result is communicated to the ESP32, which subsequently controls the appropriate actuator.

## 9. Summary

The test rig integrates **3D-printed mechanical components, an MDF structure, a NEMA 17 stepper-driven conveyor, a Futaba S3003 servo-based sorting mechanism, ESP32 firmware, and a classical computer vision pipeline** into a single prototype system.

The rig was developed to test the interaction between the mechanical conveyor system, vision-based object classification, and automated sorting mechanism.
